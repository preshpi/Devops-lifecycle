# DevOps Lifecycle

## What is DevOps?

DevOps is a culture and set of practices that bring development and IT (operations) teams together to ship software faster and more reliably.

## Core Principles

- **Collaboration:** Devs, ops, and QA work as one team with shared goals.
- **Automation:** Repetitive tasks like testing, builds, and deployments run without manual effort.
- **Continuous Improvement:** Teams measure, learn, and refine constantly.

## DevOps Lifecycle Stages

**Planning:** Teams define goals, gather requirements, and map out features using tools like Jira or Trello.

**Development:** Developers write code collaboratively, using version control systems like Git to track changes and manage branches.

**Building:** Source code is compiled and packaged into runnable artifacts using tools like Maven, Gradle, or npm.

**Testing:** Automated and manual tests run against the build to catch bugs, security issues, and performance problems before release.

**Release:** Approved builds are tagged and prepared for deployment, with version control and changelogs documenting what's shipping.

**Deployment:** The release is pushed to staging or production environments through CI/CD pipelines using tools like Jenkins, GitHub Actions, or ArgoCD.

**Operations:** Teams keep the live system running smoothly, handling infrastructure, scaling, and incident response.

**Monitoring:** Tools like Prometheus, Grafana, and the ELK stack track performance, errors, and user behavior, feeding insights back into planning.
